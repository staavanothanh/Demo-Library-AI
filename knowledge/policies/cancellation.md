# Order cancellation policy

## Cancellation window

You may request cancellation within 30 minutes of placing an order, provided the order has not entered fulfillment or been handed to the carrier. We try to honor a request quickly, but a cancellation is not guaranteed once processing has started.

## After fulfillment begins

If the cancellation window has passed, contact support anyway. If the parcel has not shipped, we will check whether fulfillment can be stopped. If it has shipped, refuse delivery when possible or follow the returns policy after delivery; do not create a duplicate order while waiting for the cancellation decision.

## Confirmation and refunds

A cancellation is complete only after you receive a confirmation message. If a payment was captured, the refund is issued to the original payment method and normally appears within 5–10 business days. A temporary authorization hold may disappear on the payment provider's own schedule.

## How to contact us

Send support the order number and the email address used at checkout. Never include a full card number, password, session cookie, or one-time passcode in a cancellation request.

## Demo environment note

This project is a bookstore demo. Its checkout can be left before completion, but it does not create a real order or charge, so there is no live cancellation or refund to process.
